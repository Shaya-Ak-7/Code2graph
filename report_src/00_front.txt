«H1»ABSTRACT
«BODY»Understanding a large code base is a time-consuming task for developers and for AI coding agents, which can read only a limited amount of text at a time. This mini project presents Code2Graph, a code-intelligence toolkit that converts a source tree into a navigable graph of symbols, files, imports, calls and inheritance relationships. Structural extraction is fully deterministic and is implemented with tree-sitter grammars, so building the code graph needs no large-language-model credits and no API key. The graph is validated, clustered into communities, analysed and exported as a Markdown report, an interactive HTML page, a per-community wiki and several standard graph formats. A Model Context Protocol server exposes query, path, neighbour, community and broken-reference tools to coding agents. A background watcher debounces file events, re-parses only the changed files, records references whose targets disappeared as BROKEN metadata, and restores them when the targets return, so no manual update step is needed.
«BODY»The implementation is evaluated in three ways. First, the toolkit is applied to its own repository: 566 code files are converted into 15,217 nodes and 35,451 edges in 23 seconds with zero model calls, and clustering produces 615 communities in 9 seconds. Second, the healing mechanism is exercised on a controlled two-file project, where deleting a file turns five edges into BROKEN records and restoring it heals all five and returns the file status to HEALTHY. Third, the engineering quality of the mini project is measured by its test suite, which reports 6,542 passing tests with 80 per cent statement coverage. The published evaluation of the upstream project, which is quoted separately and clearly labelled, reports a LOCOMO retrieval recall@10 of 0.497 and a key-fact coverage improvement on ERPNext from 70.8 to 82.0 per cent. The mini project primarily supports SDG 9: Industry, Innovation and Infrastructure.
